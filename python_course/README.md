## 🚀 How to Use This Repo

### Option 1 — Google Colab (Recommended for beginners)
Every notebook has a **"Open in Colab"** badge at the top. Click it and you're ready — no installation needed.

### Option 2 — Run Locally
1. Install Python from [python.org](https://python.org)
2. Install Jupyter: `pip install jupyter`
3. Clone this repo:
   ```bash
   git clone https://github.com/MuhammedKwanda/Python_Masterclass.git
   ```
4. Navigate to the folder and launch Jupyter:
   ```bash
   cd Python_Masterclass
   jupyter notebook
   ```
