# 📊 Week 4 Project — Student Performance Analysis

## Overview
You are a data analyst hired to explore a dataset of student exam results and provide insights to school management.

---

## Dataset
`students_performance.csv` — contains records of students with the following columns:
- `gender`, `race/ethnicity`, `parental_level_of_education`
- `lunch`, `test_preparation_course`
- `math_score`, `reading_score`, `writing_score`

Download from: [Kaggle - Students Performance Dataset](https://www.kaggle.com/datasets/spscientist/students-performance-in-exams)

---

## Tasks

### Part 1 — Load & Explore (20 pts)
1. Load the dataset into a Pandas DataFrame
2. Display the first 10 rows
3. Print the shape, column names, and data types
4. Check for missing values and duplicates

### Part 2 — Data Analysis (40 pts)
1. What is the average score for each subject?
2. Which gender performs better on average in each subject?
3. Does test preparation course affect scores? Show with groupby
4. Which parental education level correlates with highest scores?

### Part 3 — Insights & Conclusions (40 pts)
1. Write 3-5 key findings from your analysis
2. What would you recommend to school management?
3. What additional data would help your analysis?
