## 📖 Topics Covered

### 1. Introduction to Python
- History — Created by Guido van Rossum in 1991
- Python 2 vs Python 3
- Why Python? (Readable, versatile, in-demand)
- Where Python is used: Web, Data Science, AI, Cybersecurity, Automation

### 2. Variables & Data Types
```python
name = "Muhammed"       # str
age = 25                # int
gpa = 9.25              # float
is_student = True       # bool

print(type(name))       # <class 'str'>
```

### 3. Basic Operations
```python
# Arithmetic
print(10 + 3)    # 13
print(10 / 3)    # 3.333...
print(10 // 3)   # 3 (floor division)
print(10 % 3)    # 1 (modulus)
print(2 ** 3)    # 8 (power)
```
