# 🛠️ Setup Guide

Everything you need to get your Python environment ready.

---

## Step 1 — Install Python
1. Go to [python.org/downloads](https://python.org/downloads)
2. Download the latest version (3.11+)
3. During installation, **check "Add Python to PATH"**
4. Verify: open terminal/command prompt and type `python --version`

---

## Step 2 — Install Required Libraries
Open your terminal and run:
```bash
pip install numpy pandas matplotlib seaborn scikit-learn jupyter notebook
```

---

## Step 3 — Google Colab (No Installation Option)
If you don't want to install anything:
1. Go to [colab.research.google.com](https://colab.research.google.com)
2. Sign in with your Google account
3. Click the notebook links provided in each week's folder

---

## Step 4 — VS Code (Optional but Recommended)
1. Download [VS Code](https://code.visualstudio.com)
2. Install the **Python extension** by Microsoft
3. Install the **Jupyter extension**

---

## Verify Everything Works
Open Python or Colab and run:
```python
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import sklearn
print("All libraries loaded successfully! 🎉")
```
